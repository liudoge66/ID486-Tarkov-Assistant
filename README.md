# ID486 模拟助手 V0.27 PMC

面向本地PvE战局的Windows视觉监控工具。通过屏幕UI判断角色状态，不读取游戏内存、不注入游戏。

[下载最新版](https://github.com/liudoge66/ID486-Tarkov-Assistant/releases/tag/v0.27)

## V0.27 PMC

新增死亡断网保险，修复已知背包遮挡误退，并初步适配带鱼屏背包布局。

### 本次更新

- **新增“联网自动断开”开关。** 开启后先进入待命；战局内按快捷键启动监控，判定角色死亡时，并行请求结束游戏进程和断开游戏网络，作为少量退出异常情况下的补充保险。平时、正常撤离及转移期间保持联网。
- **修复多个详情窗口遮挡UI时误触发大退的问题。** 改善窗口重叠、拖动和自由拉伸的识别；背包内死亡仍继续判断，不会永久豁免。
- **初步修复21:9带鱼屏打开背包时误触发大退的问题。** 背包采用独立定位和缩放，兼容界面主体居中、两侧保留背景；3440×1440战局内效果仍需玩家实际验证。
- **改进退出执行方式。** 优先直接结束已核实的游戏进程；失败时保留快捷键及窗口关闭备用方式。
- **简化联网操作并保存开关状态。** 点击文字或滑块直接切换开启/关闭，不再弹出设置窗口；保留演练模式。
- 完善切屏、转移加载和采集空档的处理，减少旧画面、缺失观察和历史保护状态造成的误判。

### 使用前注意

**不要在“街区”地图使用。街区默认线上模式，本工具的大退与断网保护不适用，不能用于保留装备或回档。仅用于本地PvE战局。**

使用UU加速器时，请务必在“设置 → 加速设置”中关闭以下两项，确保均处于关闭状态，否则可能导致联网断开保险无法生效：

1. **解决本地 Hosts 文件域名冲突**
2. **加速时禁用网络代理**

![UU加速器需要关闭的两个选项](https://github.com/liudoge66/ID486-Tarkov-Assistant/releases/download/v0.27/UU-settings.png)

联网控制首次随监控启动时，可能出现Windows管理员授权。关闭联网开关、停止监控或退出助手会请求解除隔离；游戏断开后可能需要等待自身重试才能恢复界面。

**演练模式不执行大退，但开启联网保险后，死亡时仍会断网。** 请先验证自己的画面设置，再关闭演练模式进行实际测试。大退与断网均不保证服务器回档，已经送达的结算无法保证被撤回。

## 快速使用

1. 保持默认演练模式，进入本地PvE战局，在战斗HUD可见时按F10开启监控；再按一次停止。
2. 如需死亡断网保险，先开启“联网自动断开”开关；开启开关本身不会立即断网。
3. 确认识别符合预期后，关闭演练模式进行真实退出测试。每次触发后需要手动重新开启监控。
4. 自定义音效、音量、快捷键和其他选项可在界面中保存。

## 本地数据

程序在同目录的“PMC数据”中保存设置、导入音频和运行记录，截图按选项保存。不自动上传用户数据；分享日志或截图前请自行检查。
