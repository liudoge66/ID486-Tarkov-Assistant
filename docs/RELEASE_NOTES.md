# ID486 模拟助手 V0.31

在 V0.3 基础上改进撤离识别，加入灯塔商人区域保护和游戏关闭后的自动续接，并为每局写出结束汇总。

> **2026-11-24 更新了安装包（版本号不变）**：修复两种误判大退。已下载 11-21 版本的用户请重新下载，替换 EXE 即可。
> - 游戏还在菜单时，屏幕上的塔科夫视频被当成战斗 HUD，随后误判死亡。现在先读游戏日志，确认进入战局才开启或恢复监控。
> - 实验室电梯撤离时，倒计时数字背后有袖子和手套，读不出数字，撤离被判成死亡。现在能读出这种情况下的倒计时。

## 下载

- **ID486-V0.31-Windows.zip**：解压到可写目录，运行 `ID486模拟助手.exe`，无需 Python。
- **SHA256SUMS.txt**：ZIP 与 EXE 的 SHA-256 校验值。

从 V0.3 升级：直接用新的 EXE 替换旧的即可。数据目录不变，设置、音效和日志会保留。

发布包不含录像测试及其 PyAV/FFmpeg 专用依赖，也不包含私人配置、游戏日志、截图、录像、按键诊断或自定义音频。

## 本版重点

**撤离不再被误判为死亡**
- 撤离渐暗之后的黑屏改为锁存判断：画面全黑判为撤离，界面恢复则取消，判断不了时停止监控而不大退。
- 开着背包撤离、撤离时转动视角，现在都能正确识别。
- 修复亮场景下撤离倒计时被误认为转移倒计时的问题。

**灯塔商人区域保护**
- 通过游戏截图坐标判断是否位于商人区域，区域内不判定死亡。需要在游戏中设置截图键，助手会提示按键冲突。

**游戏关闭后自动续接**
- 监控中关闭游戏（例如 Alt+F4）后，助手等待游戏重新启动；进入新一局、出现战斗 HUD 后自动恢复监控，无需再次按快捷键。

**本局结束汇总**
- 每局结束在 `数据/运行记录.txt` 中写一段“本局结束汇总”，列出判定依据、大退与断网各步骤的时刻，以及游戏是否发出了结束请求、服务器何时响应，方便核对每次大退是否及时。

**用游戏日志确认是否在战局里（11-24）**
- 游戏日志出现 `GameStarted` 才开启或恢复监控；回到菜单时停止死亡判断，等待新一局。读不到日志时退回只看画面。

**其他**
- 可选的撤离／转移区自动暂停（默认关闭）；线上战局拒绝启动；联网命令写入被占用时自动重试；修复 DXcam 资源释放问题。

## 测试情况

判断逻辑与 11-21 版本相同的构建在本机连续实战测试中：26 局里 8 次死亡全部正确大退，且都在游戏发出结束请求之前完成；15 次撤离全部正确识别，没有误判大退。另有离线回归和保存诊断画面的回放核对。

11-24 更新后的安装包实战 7 局：1 次死亡正确大退，6 次撤离（海关 3、中心区 3）全部正确识别。两次误判的现场画面离线回放后结果正确；实验室电梯撤离与“菜单时看视频”这两个场景还没有在新安装包上实战复测。

## 使用提醒

仅用于本地 PvE，街区不适用。新用户先关闭联网保险并使用演练模式验证识别；演练模式仅禁止大退，不禁止已开启保险后的死亡断网。

- 倒计时归零前 0.3 秒以内的死亡会按撤离处理，不会大退。
- 开启“撤离／转移区自动暂停”后，撤离区内的死亡不会大退。
- 转移的实测样本较少；4:3 和超宽屏尚未在本版实测。
- 撤离／转移途中切屏可能漏掉关键画面，请尽量保持游戏前台直到过渡完成。大退与断网不承诺服务器回滚。
