# ID486 模拟助手 V0.3

面向本地 PvE 的统一版本，保留实时监控、SDR/HDR 采集、音效、快捷键、诊断和联网保险。

## 下载

- **ID486-V0.3-Windows.zip**：解压到可写目录，运行 `ID486模拟助手.exe`，无需 Python。
- **SHA256SUMS.txt**：ZIP 与 EXE 的 SHA-256 校验值。

发布包移除了录像测试及其 PyAV/FFmpeg 专用依赖；不包含私人配置、游戏日志、截图、录像、按键诊断或自定义音频。

## 本版重点

- HUD、完整界面复核与多路径渐暗死亡判断；正常撤离和转移采用独立状态机。
- 可信候选临时隔离、最终死亡并行大退与 WFP 保持，进程退出后清理。
- 配置类型容错、不可写目录回退；完整技术与场景说明见仓库 README。

## 使用提醒

仅用于本地 PvE，街区不适用。新用户先关闭联网保险并使用演练模式验证识别；演练模式仅禁止大退，不禁止已开启保险后的死亡断网。

撤离／转移途中切屏可能漏掉关键画面；请尽量保持游戏前台直到过渡完成。若已错过过程，按状态提示处理，回到战斗 HUD 后停止并重新开启。大退与断网不承诺服务器回滚。
