# ID486 模拟助手 V0.32

适配塔科夫 1.3.5（Unity 6 引擎）：修复打开背包时被误判死亡并大退的问题。

## 下载

- **ID486-V0.32-Windows.zip**：解压到可写目录，运行 `ID486模拟助手.exe`，无需 Python。
- **SHA256SUMS.txt**：ZIP 与 EXE 的 SHA-256 校验值。


## 本版重点

**1.3.5 下打开背包不再误判大退**
- 游戏更新到 1.3.5 后，背包顶部那排页签偶尔会比以前略微变窄、偏移 1 到 2 像素，原来的文字匹配因此认不出背包，几秒后就判成死亡。
- 现在背包的识别看三样互相独立的东西：页签文字（允许偏移）、页签的高亮框和格子、右上角的“返回”。任意两样成立就认定是背包。
- 战局剩余时间少、右上角出现红色计时盖住一部分“返回”时，也能认出背包。
- 切换武器时顶部弹出的快捷栏，不会被当成背包。

完整列表见 [更新记录](CHANGELOG.md)。

## 使用提醒

仅用于本地 PvE，街区不适用。新用户先关闭联网保险并使用演练模式验证识别；
演练模式仅禁止大退，不禁止已开启保险后的死亡断网。

- 开启“监控自动暂停”后，撤离区内的死亡不会大退。
- 撤离／转移途中切屏可能漏掉关键画面，请尽量保持游戏前台直到过渡完成。
