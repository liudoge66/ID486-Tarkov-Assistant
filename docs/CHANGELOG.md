# 更新记录

## V0.31 · 2026-11-21（2026-11-24 更新安装包）

### 11-24 更新（版本号不变）
- 用游戏日志确认是否在战局里：日志出现 `GameStarted` 才开启或恢复监控。修复游戏刚启动、还在菜单时，把正在播放的塔科夫视频画面当成战斗 HUD，随后在菜单界面误判死亡并大退的问题。监控中日志显示已回到菜单时，停止死亡判断并低频等待新一局。读不到游戏日志时，沿用原来只看画面的判断。
- 撤离倒计时数字背后明暗不均时（例如实验室电梯里的袖子和手套），原读法读不出数字，撤离被判成死亡。现在原读法失败时改用局部对比读取，两种参数读数一致才采用。
- 新增“游戏日志战局状态变化”等日志事件，记录日志把关的结果。

内部构建：`2026.11.24-v0.31-raid-log-71`。


### 撤离与转移识别
- 撤离候选改为锁存：倒计时接近结束、画面结构保留渐暗之后的黑屏，由新画面决定是撤离还是取消；判断不了时停止监控，不大退。修复了撤离被误判为死亡的问题。
- 开着背包撤离：观察背包界面整体渐暗，避开左上角每帧变化的性能叠加层。
- 倒计时归零窗口：倒计时连续递减时计算预计归零时刻。渐暗被转视角打乱时，只要 HUD 在归零前 0.3 秒以内仍可见、随后消失，就按撤离处理；早于这个时间的 HUD 消失仍按死亡判断。
- 读到撤离倒计时后 1 秒内忽略转移读数器，修复亮场景下撤离倒计时被误认为转移倒计时、导致撤离无法识别的问题。

### 新功能
- 灯塔商人区域保护：读取游戏截图中的坐标，在商人区域内不判定死亡，进出时各提示一次；检查截图键与系统、Steam 及助手快捷键的冲突；按距离调整截图频率，只保留助手截取的最近 5 张；截图连续失败时暂停坐标监测并提示。
- 撤离／转移区自动暂停（可选，默认关闭）：倒计时期间不判定死亡，结束后低频等待新一局。HUD 在倒计时归零前消失时提示“未确认撤离”，不再一律显示撤离完成。
- 线上战局拒绝开启监控。
- 监控中游戏进程退出（例如 Alt+F4）：识别退出并等待重新启动，界面依次提示“游戏已退出”“游戏已启动 · 等待进入战局”；新一局出现战斗 HUD 后自动恢复监控，并在此时启动结算日志与灯塔辅助。
- 本局结束汇总：每局结束在文本日志和 JSONL 日志中写出结果与依据、大退请求、窗口消失、进程退出、断网规则部署与首次拦截、游戏结束请求及服务器响应的时刻与先后。

### 稳定性
- 修复 DXcam 对 COM 引用重复释放的问题。
- 联网命令文件写入被短暂占用（WinError 5）时重试，不再因此停止本局联网保险。
- 修复游戏重启后重新绑定时因画面布局未就绪而停止监控的问题。
- 界面标题与部分提示文字调整。

首次发布内部构建：`2026.11.21-v0.31-release-70`。数据目录沿用 V0.3，升级后设置与日志不变。

## V0.3 · 2026-11-04

- 统一版本与数据目录，不再区分 PMC / Fence 下载包。
- 发布包移除录像测试入口、命令行回放分支和 PyAV/FFmpeg 专用依赖；保留自定义音效导入。
- 汇总 V0.27 后续构建已实现的 HDR 采集、共享新帧、多路径渐暗、完整 UI 复核、撤离／转移状态机、WFP 候选隔离与最终死亡保持。
- 减少同帧 HUD 评分和投影的重复计算，改进撤离渐暗序列的连续观察。
- 加入 HUD 崩塌及场景运动的网络候选依据；该分支只授权提前隔离，不单独授权结束进程。
- 配置读取统一校验根类型；数据目录不可写时回退到用户本地应用数据目录。
- 更新 README、场景处理表、切屏边界说明和构建方法；提供干净发行包与校验值。

内部构建：`2026.11.04-v0.3-release-52`。发布整理没有改变已实测版本的死亡、撤离、转移核心阈值与判定逻辑。
